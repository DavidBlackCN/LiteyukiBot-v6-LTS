# References

This plugin is implemented for LiteyukiBot v6 LTS using the repository's existing
runtime, persistence, permission and card interfaces. It does not vendor either
reference plugin or the Nitter server.

- https://github.com/nek0us/nonebot-plugin-twitter (MIT): feature reference.
- https://github.com/Nero-UMU/NitterToMaiBot (GPL-3.0-or-later): behavior reference
  for RSS subscription forwarding. Its code and artifacts are not copied.
- https://github.com/zedeus/nitter: upstream HTML/RSS format documentation.
- https://docs.libretranslate.com/api/operations/translate/: HTTP API contract.
